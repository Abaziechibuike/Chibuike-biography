Start with the basics: HTML

Every website is made of HTML. HTML tells the browser what to show. It uses tags like <h1>, <p>, and <a>.

Step 1: Open a file

Create a new file called index.html. This file will hold your first website.

Step 2: Add the page structure

Write the basic HTML parts: doctype, html, head, and body.

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>My First Website</title>
  </head>
  <body>
    <h1>Hello, world!</h1>
    <p>This is my first website.</p>
  </body>
</html>

Tip: A browser reads HTML from top to bottom, and it shows the page where each tag tells it what to do.

Understand the page structure

The main parts of a page are:

  • <html> – the whole page
  • <head> – hidden information, like the title
  • <body> – what the visitor sees

Example: The title appears in the browser tab, and the content appears on the page.

<head>
  <title>My Website</title>
</head>
<body>
  <h1>Welcome!</h1>
</body>

Style your page with CSS

CSS makes your page look nice. It changes colors, fonts, and spacing. You can add CSS inside the HTML file.

<style>
  body {
    background: #eef2ff;
    color: #1e293b;
    font-family: Arial, sans-serif;
  }
  h1 {
    color: #4338ca;
  }
  p {
    max-width: 640px;
  }
</style>

Place this CSS inside the <head> section.

Add simple interaction with JavaScript

JavaScript can make buttons do things. It can change text or show a message when someone clicks.

<button onclick="sayHello()">Click me</button>

<script>
  function sayHello() {
    alert('Hello from Chibuike School!');
  }
</script>

Step-by-step: first create the button, then make a function that runs when the button is clicked.

Build your first mini website

Combine HTML, CSS, and JavaScript to make a small page.

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>My Website</title>
    <style>
      body { background: #f8fafc; font-family: Arial, sans-serif; padding: 2rem; }
      .box { background: white; padding: 1.5rem; border: 1px solid #cbd5e1; border-radius: 16px; }
      button { background: #4338ca; color: white; padding: 0.75rem 1.2rem; border: none; border-radius: 999px; }
    </style>
  </head>
  <body>
    <div class="box">
      <h1>Welcome to my site</h1>
      <p>I am learning how to build websites step by step.</p>
      <button onclick="showMessage()">Say hello</button>
    </div>
    <script>
      function showMessage() {
        alert('Nice work! You built a website.');
      }
    </script>
  </body>
</html>

What to do next

  1. Change the words on the page to your own.
  2. Try a new color for the background.
  3. Add another button or a list of your favorite things.
💡 Every small change helps you learn more. Practice by editing the code and reloading the page in your browser.
